GitHub-ready OBJ package

Upload all five files together in the same GitHub folder:
- GEN_Box_QR_code.obj
- GEN_Box_QR_code.mtl
- DBMV_side_left.jpg
- DBMV_side_right.jpg
- README.txt

The OBJ references GEN_Box_QR_code.mtl, and the MTL references both JPG textures
using relative filenames. Do not rename or separate these files after upload.

Important: GitHub stores and serves these files, but its normal file page does not
display an interactive OBJ preview. Load GEN_Box_QR_code.obj from your GitHub Pages
viewer with its MTL and texture files in the same public directory.
